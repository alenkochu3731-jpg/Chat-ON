# Chat On

A simple Malayalam/English AI chatbot using the provided dark mobile UI.

## Setup

1. Install Node.js.
2. Open this folder in a terminal.
3. Run:

   npm install

4. Copy `.env.example` to `.env`.
5. Put your API key in `.env`.
6. Run:

   npm start

7. Open http://localhost:3000

Never put your API key inside `index.html` or browser JavaScript.
